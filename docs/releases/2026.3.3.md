# ++PHP 2026.3.3

Use a `when` expression directly with `.=` to append the selected branch value. Intermediate conditions accept either `else when` or `elsewhen`, followed by a final `else`.

~~~php
string $message = 'Status: ';
$message .= when ($score >= 80) {
    return 'excellent';
} elsewhen ($score >= 50) {
    return 'pass';
} else {
    return 'retry';
};
~~~

The assignment uses PHP's concatenation rules. If a branch throws, the append does not occur. If you write `elseif` or `else if` inside a `when` expression, the compiler now highlights that keyword and suggests `else when`.

Browser Check and Build use PHPStan for projects outside the compiler's fast analysis path. Successful browser builds still pass PHP lint. Native Check and Build continue to use supplemental PHPStan analysis.

## Compatibility and Upgrade

The compiler requires PHP `^8.4` and Composer 2. Generated PHP targets PHP 8.4. After updating the compiler, rebuild your generated output from project sources.
