# ++PHP 2026.3.2

This release reduces the wait after clicking Build on edited code in a compatible browser editor. The editor can reuse verified PHP platform signatures and prepare the compiler while you pause after editing. Both PHPStan passes and PHP lint still run before the editor accepts generated output.

Browser builds now limit how much compiler workspace data they retain. If a cached syntax entry fails its integrity check, the compiler reparses the installed signature source.

## Compatibility and Upgrade

The compiler still requires PHP `^8.4` and Composer 2. Generated PHP continues to target PHP 8.4. After updating the compiler, rebuild the generated output from your project sources. Browser integrations should ship the matching editor and compiler assets together.

Report bugs through [GitHub Issues](https://github.com/atatusoft-ltd/ppphp-src/issues) and include the output of `vendor/bin/ppphp --version`. Follow the security policy linked below to report vulnerabilities privately.
